## 範囲と受入条件

- PCは260pxの一覧と64pxのバーを切り替え、閉じた領域のリンクへフォーカスが入らず、本文が空いた幅を使う。SPの一覧・模試ごとの開閉は維持し、表示幅を切り替えても操作できる。
- 全級の設定由来の模試一覧を最初のHTMLから表示する。認証応答の待機・失敗で一覧を隠さず、開閉でも問題APIを呼ばない。
- 初回のクライアント描画をグローバル認証確認で止めない。認証確認自体、個別のauth/admin guard、APIの権限検査とSSRのprivate/no-storeは維持する。資格不明の有料枠はロックし、確認後・資格失効・ログアウトを反映する。
- 各級の問数、20案内枠、無料3回と実収録範囲を保つ。料金・教材・DB・Stripe・メール・障害通知の設定は変更しない。
- 関連自動検査、使い捨てtest DBのPC/SP操作、静的HTMLと認証応答を保留/失敗させた検査、別担当の認証境界レビューを行う。

開始時点のHEADは`25ab5f3`。別作業のAGENTS.mdの1級参考資料方針は保持し、今回のGit送信へ含めない。実装・ローカル検証・独立レビューをstateで管理する。検証後は対象変更だけをローカルコミットし、push・本番反映は行わない。
