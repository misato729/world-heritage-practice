## 初期構成

- 世界遺産検定2級。10回・各60問、選択肢①〜④、5大分類とテーマ別の小分類。
- 初期教材0件。テスト用合成データは公開用JSONから分離し、専用DBに明示投入する。
- サービス名、独自の地球と本のSVG、森林色、試験概要、準備中・未公開問題の案内を用意する。
- Compose・DB・ポート・Cookie識別子を独立させる。販売は無効。
- `past-exam/` と `local-only/` を資料保護ポリシー・Git・Dockerで除外する。
- 派生元の作業記録・完了履歴・スクリーンショットを持ち込まず、新しい履歴を開始する。
