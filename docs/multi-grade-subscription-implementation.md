# 3級種統合・月額プランの実装記録

2026年11月6日の実装依頼。価格は月額500円（税込）、各級の模試1〜3無料・4以降有料。販売開始・実環境設定・コミット/pushは含まない。

## 実装

- 1級・準1級・2級を同じアプリで切替。級は `?grade=1|pre1|2` とAPIの `X-Exam-Grade` で明示。省略は既存の2級。各リンクにも級を付け、新タブ・コピー先でも維持する。級切替時は再読み込みして回答・復習・遅延応答を破棄する。
- 設定と共有Zodで級を管理。1級90問、準1級・2級60問。問題・公開判定・管理・履歴・お気に入り・復習・達成度を級別に抽出。教材は追加していない。
- 追加マイグレーションで既存問題へ2級を付与。ID・本文・履歴・お気に入りの再作成はしない。旧一回払い資格は2級の従来資格として保持する。
- 新規購入はStripeのsubscription Checkout。税込JPY500・monthly/1・税込Priceだけ受理し、カード決済・割引なし・自動税加算なし。署名検証済みイベントと最新の契約・支払済み請求書に基づいて期間を記録し、APIが利用期限を確認する。
- 更新失敗時は確認済み期間のみ維持し追加猶予は与えない。トライアルなし。解約・支払方法は共通のCustomer Portalへ案内。期間末解約は支払済み期間まで、退会時は即時に今後の請求停止を確認してから削除する。
- 新契約は旧Membershipと別テーブル。新契約が無期限の旧資格を作らない。イベントの再送は既存のイベント一意性で防ぐ。古い通知でも最新の契約と照合する。

## 返金・紛争時の運用

新しいサブスクの返金・紛争に伴う自動失効は今回実装していない（旧一回払いの処理は保持）。通常の期間末解約と区別し、返金・紛争で有料利用を停止する場合は、担当者がStripeで対象の本サービス契約を即時停止し、Webhookまたは `subscriptions:sync` でcanceledと期限の反映を確認してから返金等を扱う。返金だけでは資格が失効しないため、この手順と問い合わせ対応を販売前に確認する。日割り・返金可否の商用条件と自動処理の追加は別途決定する。
