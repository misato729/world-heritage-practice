# 再設定メールと障害通知の本番設定（2026-11-15）

## 依頼・受入条件

ユーザーの「パスワード再設定メールと障害通知も、他のラボと同じように設定してください」に基づき、世界遺産ラボ専用のGoogle Apps Script再設定メールとSentry通知を設定する。既存ラボの設定・鍵・契約・利用者は変更・流用しない。Git配信は含めない。

- 同梱のGASコードと最小権限のmanifestを専用projectへ配置し、独立した鍵、固定origin、サービス名を設定する。
- Googleアカウントの送信承認後、本人権限・匿名アクセス可能な専用`/exec`を配信し、Flyの秘密領域へURL・鍵と有効化設定を登録する。

- Googleメール配送とSentry通知を公開プライバシーポリシーへ記載し、PC/SPで表示確認する。対象版・配信結果・独立レビュー・未確認事項を記録する。

## 運用上の範囲

再設定リンクは30分・1回限りで、再設定後は古いセッションを無効にする。アプリ/GASの日次配送上限は20件で、Googleアカウント自体の送信枠は同じ送信者の他projectと共有する。メールの遅延や迷惑メール判定もあり得るため、依頼画面は到着保証として表示しない。

障害通知の対象は既存実装のAPI 5xx、Stripe API、Stripe webhookの固定カテゴリである。自動計測、リクエスト、利用者、例外本文、添付、問題・解答、Stripeイベント本文は収集しない。同じ分類・環境はプロセスごとに1時間抑制し、送信は1秒で中断し再試行しない。Sentry側にも1時間の通知間隔がある。

メール配送失敗は現行実装では固定カテゴリのローカルログにだけ記録され、Sentry通知には含まれない。サービス全体の停止を検出する外形監視も今回の範囲に含めない。通知成功を全種類の障害検知や配送保証として扱わない。
