# 世界遺産ラボの教材データ

`questions.json` は `schema_version: 1` の教材正本です。2級模試1〜10の各60問、合計600問を収録します。各回の問題、解答解説、解答用紙を `mock-exam-NN.questions.md`、`mock-exam-NN.answers.md`、`mock-exam-NN.answer-sheet.md` に保存しています。[模試6〜10の作成・確認記録](../docs/grade2-mocks-06-10-20261114.md)を参照してください。

試験設定は `config/exam.json`、形式の正本は `frontend/shared/schemas/` です。公開セットは問1〜60をそろえ、選択肢①〜④、正答1件、解説・出典を含めます。登録前には [カスタマイズ手順](../docs/customization.md) を確認します。

動作検証用の合成データは `frontend/test-support/` で生成し、test専用DBへ明示して投入します。ここに保存せず、通常起動のseedや公開コンテンツには使用しません。

参照した公式テキストは第5版第2刷です。書籍の出典は印刷ページと見出し、時事の出典は年次・公式一次資料・確認日を各問へ記載します。`past-exam/`・`textbook/` とその抽出本文・原本画像、内部の作問・検証資料はローカル専用です。Git、Docker、外部ストレージ、CI成果物へ含めません。

開発時の自動seedは問題・選択肢が空のDBだけに投入し、既存問題を上書きしません。既存DBへの追加は、バックアップと独立したtest用DBでの復元・整合確認を経て、共通の書込み処理を使います。無料は各級模試1〜3、4以降は有料枠です。教材の追加は販売開始や本番公開を意味しません。
